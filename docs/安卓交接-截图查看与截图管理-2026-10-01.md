# 交接说明：截图查看与截图管理

日期：2026-10-01  
来源：Windows 桌面版现在的「截图预览 / 看图模式」和「截图管理」。  
目的：安卓版做出同等能力。功能要齐，分区、按钮名字、操作顺序和视觉气质尽量跟电脑一脉相承。手机和电脑填同一个用户名，改的是同一张截图。

截图怎么存、怎么同步，仍按 `docs/安卓交接-截图同步-2026-09-30.md`。  
创建/编辑截图对话框仍按 `docs/安卓交接-创建编辑截图-2026-10-01.md`。  
笔记框的拖动、缩放、样式面板仍按 `docs/安卓交接-截图笔记浮动控件-2026-09-30.md`（本文会补充桌面版后来定下的交互，与旧交接冲突时以本文为准）。

此前「创建/编辑截图」交接里写过「这次不要做查看截图」。那条作废。本次就要做查看，并且要做截图管理。

安卓只做客户端。不要改服务器、Nginx、数据库。

桌面版参考（只读）：

## 1. 两个入口

播放器工具栏里，在「画面字幕」一类按钮附近有两个入口，顺序固定：

1. **截图管理**
2. **截图预览**

「截图预览」只在当前视频已有截图时可点。  
「截图管理」随时可点，不依赖当前是否打开了视频。

字幕列表里，截图行长按菜单仍是：

- 查看截图
- 编辑截图
- 删除截图

「查看截图」打开第 2 节的看图模式，轮播范围是**当前这部视频**的全部截图。  
从「截图管理」点查看进入时，轮播范围是**管理列表里的全部截图**（可跨多个视频），见第 5 节。

## 2. 看图模式（截图预览）

### 2.1 怎么盖在播放器上

看图层盖在播放画面区域上，黑底。底图按比例缩小后居中，上下或左右空白是黑的。

打开看图、关闭看图，都不要改变视频的播放/暂停状态。用户本来在播就继续播；本来暂停就继续暂停。声音也可以继续，不必强制静音。

第一次进入看图时，画面中上部出现一条短暂提示（约 3 秒淡入淡出），文案固定为：

```text
已退出播放模式，进入看图模式。
点击右上角关闭图标可退出看图模式，返回播放模式。
```

提示是深紫半透明圆角卡片，浅字，黄紫描边感与截图相关控件一致。提示消失后不要再自动出现，除非再次从播放切进看图。

### 2.2 浮层按钮（没有侧栏，没有底栏工具条）

不要在画面旁边或底下再做一排固定工具栏。控件都浮在底图所在画面上：

| 控件 | 位置 | 说明 |
| --- | --- | --- |
| 关闭 | 右上角 | 图标按钮，退出看图，回到播放界面 |
| 上一图 / 下一图 | 画面右侧中部，竖排 | 在当前轮播范围内切换 |

按钮配色要跟着背后画面明暗变：

- 背后偏亮（白板课件）：深色底 + 亮黄字/描边
- 背后偏暗（黑板画面）：浅色底 + 深紫字 + 亮黄描边

安卓可用同样规则采样按钮背后区域的平均亮度，阈值可取约 `0.55`。

左右键或左右滑动可切图，效果与上一图/下一图相同。到第一张时「上一图」不可用，到最后一张时「下一图」不可用。

标题栏或系统返回：优先只退出看图，不要直接退出整个播放器。整个播放器要退出时，见第 6 节。

### 2.3 笔记怎么出现

当前这张截图的全部笔记，直接浮在底图上显示（相对底图矩形的比例坐标，见浮动控件交接）。

多条笔记时，按创建时间编号为 `Note 1`、`Note 2`……只有一条时不加编号标题。

点一条笔记：它成为激活项，样式面板出现，只改这一条。  
再点空白处：收起样式面板（笔记框仍可留在画面上，按浮动控件交接）。

在笔记框上长按（电脑是右键），菜单文案：

- 编辑笔记
- 复用 Note N 样式（仅当本张还有其它带编号的笔记时出现；没有编号的单条不出现此项）
- 删除笔记 / 删除 Note N 笔记

「编辑笔记」进入该条正文编辑。  
「复用 … 样式」只拷贝来源笔记的尺寸和样式，**保留当前笔记的位置**；写回这条笔记的 `box`，并持久化、同步。  
「删除笔记」删掉这条，写回 `screenshots.json` 并同步。

位置、大小、透明度、字号、颜色、对齐的拖动与样式面板，按浮动控件交接；改完要写入该笔记 `box`，并更新截图 `updated_at`。

### 2.4 空白处菜单与「截屏保存」

在底图空白处长按（电脑是右键），菜单两项：

- 编辑截图
- 截屏保存

「编辑截图」打开创建/编辑截图对话框，改标题和笔记正文，规则与创建编辑交接相同。

「截屏保存」把**当前底图 + 当前显示的笔记**合成一张普通 JPEG，弹出系统保存对话框。  
这张图：

- **不**写入 `screenshots.json`
- **不**上传云端
- **不**出现在「截图管理」列表里
- 以后只能当普通图片，由系统文件管理器管理，不能再在本 App 里改标题或笔记

默认文件名：`zm-截图标题.jpg`。标题为空时用 `zm-截图.jpg`。`zm` 表示「字幕」，方便用户在相册或文件夹里筛选。用户可在保存对话框里改名。记住上次保存的文件夹，下次从那里开始。

第一次使用「截屏保存」时，先弹出 tip 提示框（可复用组件，见第 7 节）：

- 标题：`tip`
- 正文：`此功能是将当前笔记和图片截屏保存为一张普通图片。`
- 勾选项：`下回不再提醒`
- 右下角按钮：`我知道了`

点「我知道了」关闭 tip，再继续保存流程。若勾选了「下回不再提醒」，本设备以后再进「截屏保存」不再出 tip。

合成图里不要画出：激活紫边、缩放手柄、样式面板、上一图/下一图/关闭等浮层按钮。

### 2.5 从当前视频进入时的轮播范围

从「截图预览」按钮，或从字幕列表「查看截图」进入：

- 列表 = 当前视频 `screenshots.json` 里的全部截图，按时间排序
- 默认落到最接近当前播放时间的那一张；若点的是某一行，就打开那一张

在这张上改标题、笔记、`box`，都写回当前视频，并按同步交接上传。

## 3. 截图管理对话框

### 3.1 怎么打开

点工具栏「截图管理」。对话框标题是「截图管理」，标题栏右侧有关闭。深色风格，与播放器其它对话框一致。

### 3.2 选文件夹

顶部一行：

```text
文件夹  [路径只读输入框………………]  [选择文件夹]  [最近打开]
```

- 「选择文件夹」：系统选目录对话框。
- 「最近打开」：下拉列出本机最近选过的管理文件夹（大约 15 个）。没有时显示不可用的「暂无最近打开的文件夹」。
- 选中后记住这个文件夹，下次打开管理对话框可直接回到它。

### 3.3 什么叫有效截图

只认视频配套目录里的正式截图：

```text
某视频.mp4
某视频.mp4.data/screenshot/screenshots.json
某视频.mp4.data/screenshot/{截图编号}.png   （或云端下来的 .webp）
```

判定规则：

1. 所选范围内存在对应视频文件；
2. 其配套 `screenshots.json` 里登记了该截图；
3. 图片文件实际存在。

「截屏保存」导出的 `zm-*.jpg` **一律不算**，即使放在同一棵目录树里也不进列表。

扫描顺序必须是**广度优先**：

1. 先当前文件夹内各视频的截图；
2. 再第二层子文件夹内的；
3. 再第三层……

同层内按视频文件名排序。名为 `*.data` 的配套目录不算用户目录层级，不要当成一层去「找视频」。

### 3.4 列表列

列从左到右固定为：

| 列 | 内容 |
| --- | --- |
| 序号 | 全局序号，单元格水平垂直居中 |
| 截图标题 | 来自 `screenshots.json` 的 `title`，空则「截图」 |
| 路径 | 相对所选根文件夹的路径，不要写盘符绝对路径 |
| 笔记 | 这条截图有几条笔记（数字，居中） |
| 创建时间 | `yyyy-MM-dd HH:mm:ss` |
| 修改时间 | `yyyy-MM-dd HH:mm:ss` |
| 查看 | 只放一个小图标按钮，不要写「查看」两字；提示文字可以是「查看」 |

创建时间、修改时间优先用 json 里的 `created_at` / `updated_at`。缺了、为 0、或无法解析时，用图片文件的保存时间补全。

摘要行示例：

- 有结果：`共找到 N 个截图（不含截屏保存导出的普通图片）。`
- 没有：说明需要有对应视频且 `screenshots.json` 有登记，并写明截屏保存的普通图片不在此列。

### 3.5 分页

列表下方：

```text
分页  ○ 全部  ○ 按路径     [上一页]  第 x/y 页  [下一页]
```

- **全部**（打开对话框时的默认）：一次列出扫描到的全部有效截图，用垂直滚动看完。页签文案可用「全部 N 条」。
- **按路径**：同一相对目录下的截图在同一页；下一页是下一个路径分组的全部截图。某一路径下条数再多，也仍在这一页里，用垂直滚动看完，不要再按条数拆页。

不要做「按条分 / 每页 5/10/20」。

### 3.6 从列表「查看」

点某一行的查看图标：

1. 先收起或隐藏管理对话框，露出播放器画面上的看图层；
2. 进入第 2 节的看图模式；
3. **上一图 / 下一图的范围 = 本次管理列表里的全部条目**（跨视频也要能切）；
4. 仍可编辑标题、笔记、`box`，写回**该截图所属视频**的 `screenshots.json`，并同步该视频；
5. 关掉看图后，回到截图管理对话框，并刷新当前文件夹列表（标题、笔记数、时间可能已变）。

若当前播放的视频不是正在查看的那部，不要强行 seek 错视频；编辑对话框里的「从字幕取句」可以没有字幕列表，但不影响改标题和笔记。

## 4. 视觉与电脑一脉相承

安卓在布局密度上可以按手机适配，但尽量保持这些气质：

- 深色底（约 `#2b2b2b` / `#393939`），白或浅灰字；
- 截图相关强调色：紫 `#3A2458`、浅紫边 `#E2C6FF`、亮黄 `#FFE14A`；
- 看图时浮层按钮要「能看清、不与白板/黑板糊在一起」，按第 2.2 节自适应；
- 管理列表是深色表格，行可选中；查看列只有图标，不要又高又宽的文字按钮；
- tip、确认框用短中文，按钮名与电脑一致：「我知道了」「下回不再提醒」「取消」「保存」等。

手机竖屏时，管理对话框可全屏或接近全屏；看图仍应盖在播放画面上，而不是另开一个完全脱离播放器上下文的陌生浏览页。

## 5. 轮播范围对照

| 入口 | 上一图 / 下一图范围 |
| --- | --- |
| 工具栏「截图预览」 | 当前视频全部截图 |
| 字幕列表「查看截图」 | 当前视频全部截图 |
| 截图管理列表「查看」 | 本次管理扫描得到的全部截图（可跨视频、跨子目录） |

不要在「管理查看」里切到下一张时，偷偷缩回「只剩当前视频」。

---

## 6. 退出播放器要确认

看图模式下，画面上有关闭按钮，系统标题栏或手势也常有关闭/返回。用户容易误关整个 App。

关闭整个字幕播放器应用之前，先问：

「确定要退出当前字幕播放器应用程序吗？」

按钮：否（默认）、是。选「否」则继续留在应用里。

---

## 7. 可复用 tip 提示框

电脑把 tip 做成了可复用组件（`tip_dialog.py`）。安卓也做成同一套小组件，供多处使用：

- 标题默认 `tip`
- 正文可配置
- 勾选「下回不再提醒」
- 右下角「我知道了」
- 每个 tip 有稳定 `tip_id`；勾选后写入本机配置，同一设备同一 `tip_id` 不再弹出

截屏保存使用的 `tip_id` 建议与电脑一致：`screenshot_export`。

## 8. 安卓这次要做出的结果

1. 工具栏有「截图管理」「截图预览」；列表「查看截图」能进入看图。
2. 看图盖在播放画面上，不打断播放状态；有模式提示、右上关闭、右侧上一图/下一图，按钮对比度自适应。
3. 笔记浮在底图上，可点选、改样式、长按编辑/复用样式/删除；改动能持久化并同步。
4. 空白处可「编辑截图」「截屏保存」；截屏保存有 tip，导出 JPEG 不进云端、不进截图管理。
5. 截图管理可选文件夹、最近打开、广度优先扫描、列表七列、全部/按路径分页。
6. 从管理进入查看时，轮播范围是整份管理列表，仍可编辑，关闭后回到管理并刷新。
7. 退出整个播放器前有确认。

---

## 9. 不要做

- 不要把「截屏保存」的 JPEG 当成正式截图写入 `screenshots.json` 或上传。
- 不要用文件名是否叫 `zm-` 来判断管理列表里的有效截图。
- 不要在管理里做「按条分」分页。
- 不要把查看做成完全脱离播放器的第三方相册式浏览器，丢了笔记浮层和编辑能力。
- 不要在看图时用固定侧栏/底栏代替浮层按钮。
- 不要让管理查看的上一图/下一图只在单个视频内打转。
- 不要改服务器接口或数据库。
- 不要在没有确认的情况下，因误点系统关闭而直接退出整个播放器。
