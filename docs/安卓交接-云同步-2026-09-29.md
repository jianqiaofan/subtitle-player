## 1. 服务器地址

正式地址只有这一个：

`https://subtitle.gcsfg.work`

- 使用 HTTPS。安卓 9 及以上不要走明文 HTTP，也不要把 IP 和端口写进客户端。
- 路径前缀是 `/api/...`，例如 `https://subtitle.gcsfg.work/api/health`。
- 健康检查不需要登录，返回 `{"status":"ok"}`。
- 字幕正文上限 8MB。标签 JSON 上限也是 8MB。超过返回 413。
- 登录后的请求带 `Authorization: Bearer <access_token>`。
- 错误正文是 `{"detail":"中文说明"}`。把 `detail` 直接显示给用户。
- 令牌有效期 30 天。收到 401 时用保存的用户名和密码再登录一次。仍失败就回到登录界面。

电脑上已经注册过的账号在这台服务器上。手机用同一个用户名和密码登录即可。本机 `127.0.0.1` 上的旧库不要再使用。

## 2. 账号

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/auth/register` | 成功 201，并直接返回令牌 |
| POST | `/api/auth/login` | 成功 200，返回令牌 |
| GET | `/api/auth/me` | 返回 `{"username":"..."}` |

成功体：

```json
{"access_token":"...","token_type":"bearer","username":"zhangsan"}
```

规则：

- 用户名 3 到 32 个字符，只能包含字母、数字、下划线、点和短横线，并且至少有一个字母或数字。前后空格直接去掉。中间有空格时提示「用户名中间不能有空格。」
- 密码 8 到 72 个字符。
- 注册得到 409「用户名已存在」时，不要自动登录。把注册按钮停用，直到用户名、密码或服务器地址有一处被修改，再允许注册。
- 不同设备填写同一个用户名，就是同一个用户。空用户名时，在设置和发起云操作前提示注册。不要每打开一个视频都弹注册框。

## 3. 一部视频是什么

视频文件留在手机本地，云端只存字幕和标签。云端没有文件夹层级。

身份是视频内容的 SHA-256，64 位小写十六进制，不是文件名。

- 改名、原样复制：哈希不变，字幕和标签仍对得上。
- 重新压制、剪辑、转码：内容变了，是新视频，旧字幕不会自动跟过去。

语言身份是主文件名后面的那一段：

| 视频主文件名 | 字幕文件名 | 语言后缀 |
|---|---|---|
| 第1课 | 第1课.srt | `.srt` |
| 第1课 | 第1课_中文.srt | `_中文.srt` |
| 第1课 | 第1课_英文.vtt | `_英文.vtt` |

云端唯一键是 `(用户, 视频哈希, 语言后缀)`。同一种语言后再上传，只覆盖这一种语言，其它语言保留。

下载写回本地时，文件名用**当前视频的主文件名 + 语言后缀**。云端记录里的旧文件名只说明它当初从哪部视频传上来，不要照旧文件名落盘。例如视频已改名为 `复习.mp4`，下载到的中文字幕应是 `复习_中文.srt`。

### 3.1 哈希文件

播放器第一次打开视频时计算 SHA-256，并写在视频旁边：

`第1课.mp4.videohash.json`

```json
{"hash":"<64位小写十六进制>","size":12345,"mtime_ns":67890}
```

`size` 和 `mtime_ns` 与视频文件一致时，直接用里面的 `hash`，不要再读完整文件。这两个值变了再重算。

从云端管理里上传字幕时，**让用户选字幕文件，不要先选视频**。到字幕同一文件夹里找 `视频全名.videohash.json`，从中取出合法哈希。对不上就拒绝上传，并说明原因：

- 同目录没有这种哈希文件：请先用播放器打开对应视频，同目录会生成该文件。
- 哈希文件名不是「视频全名.videohash.json」。
- 字幕名和视频主文件名对不上。字幕名必须与主文件名相同，或只在后面加 `_语言`。
- 文件里的 `hash` 不是 64 位小写十六进制。
- 同时对上多个不同的哈希，无法确定是哪一部视频。

同目录里主文件名更长的视频优先认领。`第1课_复习.srt` 对上 `第1课_复习.mp4`，不要对上更短的 `第1课.mp4`。

批量上传是选一个文件夹，里面每个 `.srt` / `.vtt` 都按上面同一条规则。能确定视频的继续上传，不能确定的在结果里写明原因。

## 4. 打开视频时自动检查

必须在后台做，不能卡住播放。离线或服务器连不上时静默跳过，不要弹错误框。

顺序：

1. 用这部视频的哈希调用 `GET /api/sync?video_hash=`。
2. 自己的字幕：云端正文和本地文件不同，或本地还没有这个语言后缀的文件时，列出文件名和云端时间，询问是否写入本地。相同内容不要再问。
3. 自己的标签：云端这份和上次同步记录不同，或者本地 `.tags.json` 不在、里面已经没有可见标签时，询问是否合并。云端没变且本地标签文件还在，就不要再问。
4. 别人分享的字幕：仅当这部视频在本地**一份有效字幕都没有**时才提供。已经有本地字幕，或刚才同意下载了自己的字幕并写到本地之后，不再提供别人的。

同步记录按用户保存在本机，键是 `视频哈希/语言后缀`。记下云端的 `content_hash` 和 `updated_at`。标签还要记下当时的云端文档，供下次只上传差异。

`GET /api/sync` 返回：

```json
{
  "video_hash": "<64位>",
  "subtitles": [
    {
      "subtitle_name": "第1课_中文.srt",
      "subtitle_suffix": "_中文.srt",
      "content": "字幕正文",
      "content_hash": "<64位>",
      "updated_at": "2026-09-29T08:00:00Z"
    }
  ],
  "tags": [
    {
      "subtitle_name": "第1课_中文.srt",
      "subtitle_suffix": "_中文.srt",
      "content_hash": "<64位>",
      "updated_at": "2026-09-29T08:00:00Z",
      "document": {"version": 2, "subtitle_file": "第1课_中文.srt", "entries": []}
    }
  ]
}
```

时间是 UTC，界面显示成本地时间，格式 `YYYY-MM-DD HH:MM`。

## 5. 上传字幕

`PUT /api/subtitles`

```json
{
  "video_hash": "<64位小写>",
  "video_stem": "第1课",
  "subtitle_name": "第1课_中文.srt",
  "content": "字幕正文",
  "shared": false
}
```

`shared` 默认 false。上传前单独询问：「共享」或「仅自己使用」。取消则不上传。

云端已有同一种语言且正文不同时，先问是否替换。单文件是「替换 / 取消」。批量是「替换 / 跳过已有 / 取消」。正文哈希相同则视为已是最新，不再上传。

成功后记下该语言的 `content_hash` 基线。

## 6. 上传标签

本地标签文件仍是 `docs/安卓交接-字幕标签与近期改进.md` 的 version 1，并保留 `tag_ops` 和 `note_at`。U 盘上的「同步标签文件」「批量同步标签」「提取全部标签」仍是追加合并，不要改成云端这套。

发给服务器的文档必须是 **version 2**，而且只包含自上次云端基线以来有变化的句子。服务器拒绝「只带 `tags` 数组、没有 `tag_ops`」的文档。

`PUT /api/tags`

```json
{
  "video_hash": "<64位>",
  "video_stem": "第1课",
  "subtitle_name": "第1课_中文.srt",
  "document": {
    "version": 2,
    "subtitle_file": "第1课_中文.srt",
    "entries": [
      {
        "id": "sentence1",
        "index": 1,
        "start": 1.0,
        "end": 2.0,
        "text": "同一句",
        "tag_ops": [
          {"name": "重点", "present": true, "at": "2026-09-29T08:00:00Z"}
        ],
        "note": "",
        "note_at": "2026-09-29T08:00:00Z"
      }
    ]
  }
}
```

合并规则：

- 同一句、同一个标签名，时间较新的 `tag_ops` 生效。`present: false` 是删除，必须保留，不能把标签从数组里直接丢掉。
- 备注以较新的 `note_at` 为准。
- 这次上传里没提到的标签保持云端原样。
- 播放器里取消一个标签时，要写成 `present: false` 并带上时间，不能只从 `tags` 里删掉名字。
- 标签不共享。没有共享开关。

下载时按操作时间把云端文档并进本地文件，然后把这次云端文档记成新基线。本地多出来的标签留在手机上，下次上传再送上去。

## 7. 别人分享的字幕

标签不能被别人看到。字幕默认仅自己使用。只有上传时选择了共享，别的用户才能看见。

`GET /api/shares?video_hash=<64位>`  
只返回**其他用户**已共享的字幕，不含正文。自己的共享不会出现在自己的这份列表里。按分享人分组，最近更新的人排在前面。

```json
{
  "video_hash": "<64位>",
  "shares": [
    {
      "username": "zhangsan",
      "updated_at": "2026-09-29T08:00:00Z",
      "subtitles": [
        {
          "subtitle_name": "第1课_中文.srt",
          "subtitle_suffix": "_中文.srt",
          "content_hash": "<64位>",
          "updated_at": "2026-09-29T08:00:00Z"
        }
      ]
    }
  ]
}
```

界面让用户看到分享人的用户名、该组最新时间，以及有哪些字幕。用户选定一个人之后再取正文：

`GET /api/shares?video_hash=<64位>&username=zhangsan`

这次返回的每条字幕带 `content`。一次写入这个人在这部视频上所有已共享的语言。写盘规则仍是「当前视频主文件名 + 语言后缀」。没有这个用户的共享时返回 404。

用户取消了「下载自己的云端字幕」之后，只要本地仍然没有字幕，仍可以接着选择别人的分享。自己的字幕一旦写到本地，就不要再弹出分享列表。

## 8. 云端管理

在账号或设置里提供「云端管理」。两个列表：「字幕管理」和「标签管理」。只显示当前登录用户自己的内容。

两个列表的第一列都是复选框。勾选多项后可以一起删除。没有勾选时，对当前这一行操作。点表头可以全选或取消全选。查看始终只打开当前这一行。

### 8.1 字幕

`GET /api/library/subtitles` 只返回摘要，不含正文。列：字幕文件、视频主文件名、更新时间、共享或仅自己。

```json
{
  "subtitles": [
    {
      "id": 1,
      "video_hash": "<64位>",
      "video_stem": "第1课",
      "subtitle_name": "第1课_中文.srt",
      "subtitle_suffix": "_中文.srt",
      "shared": false,
      "updated_at": "2026-09-29T08:00:00Z"
    }
  ]
}
```

| 操作 | 接口 |
|---|---|
| 查看正文 | `GET /api/library/subtitles/{id}`，结果多一个 `content` |
| 改是否共享 | `PATCH /api/library/subtitles/{id}`，正文 `{"shared": true}` 或 `false` |
| 删除 | `DELETE /api/library/subtitles/{id}`，返回 `{"deleted": id}` |
| 新增 | 按第 3.1 节选字幕并取出哈希，再 `PUT /api/subtitles` |

共享按钮：

- 选中的都是仅自己：按钮为「设为共享」，全部设为共享。
- 选中的都已共享：按钮为「取消共享」，全部取消。
- 两种都有：先问「全部设为共享」还是「全部取消共享」。

删除前确认。删除后其他设备也不能再同步这份字幕。别人的 id 返回 404「没有这条字幕」，不要据此判断那条字幕是否存在。

### 8.2 标签

`GET /api/library/tags` 同样只有摘要。列：标签对应的字幕名、视频主文件名、更新时间。没有共享列。

| 操作 | 接口 |
|---|---|
| 查看 | `GET /api/library/tags/{id}`，结果多一个 `document`。展示每句的正文、仍显示的标签和备注 |
| 删除 | `DELETE /api/library/tags/{id}` |
| 新增 | 选择视频旁边的 `字幕名.srt.tags.json`，确认字幕名与视频匹配后，按第 6 节上传 |

没有「修改标签正文」的接口。改标签内容是在播放器里改本地文件，再按差异重新 `PUT /api/tags`。

## 9. 安卓这次要做出的界面

不必照搬桌面控件，结果要一致：

1. 设置里有用户名、密码、服务器地址。默认服务器是 `https://subtitle.gcsfg.work`。注册、登录、云端管理放在一起。
2. 打开视频后后台检查自己的字幕、自己的标签，以及在本地完全没有字幕时别人的分享。
3. 上传字幕前询问共享或仅自己使用。同语言内容不同时询问替换。
4. 云端管理两个列表，第一列复选框，支持批量删除。字幕支持批量改共享。
5. 字幕上传从选择字幕文件开始，用同目录哈希文件确定视频。批量上传同样遵守。
6. 网络失败时，打开视频的自动检查保持安静。用户主动点的上传、登录、云端管理要显示 `detail`。

## 10. 不要做

- 不要把视频上传到服务器。
- 不要按文件名或文件夹去云端找字幕。没有哈希文件就拒绝上传并说明原因。
- 不要在用户已经有本地字幕时，再推荐别人的分享。
- 不要把标签分享给其他用户。
- 不要用整份标签快照覆盖云端。上传用 version 2 的差异，下载按操作时间合并。
- 不要改 U 盘三项标签同步的追加合并。
- 不要部署或重启服务器上已有的采购系统和 FansTool。
