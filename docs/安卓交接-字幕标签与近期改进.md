# 交接说明：字幕标签与近期播放器改进

日期：2026-09-25  
来源：Windows 桌面版（Python + PyQt6）今天已实现的行为。  
目的：安卓版按同一套规则实现，使两边的标签文件可以互相拷贝、互相打开。

桌面版参考实现：

- 标签读写与对齐：`subtitle_app/core/subtitle_tags.py`
- 列表展示与筛选：`subtitle_app/gui/subtitle_list_delegate.py`、`subtitle_app/gui/tag_filter_bar.py`、`subtitle_app/gui/player_window.py`
- 打标签对话框：`subtitle_app/gui/subtitle_tag_dialog.py`
- 备注预览与编辑：`subtitle_app/gui/subtitle_note_popup.py`
- 画面字幕与字幕列表开关：`subtitle_app/gui/onscreen_subtitle.py`、`subtitle_app/gui/player_window.py`
- 批量同步标签：`subtitle_app/gui/batch_tag_sync_dialog.py`、`subtitle_app/core/subtitle_tags.py`

安卓界面不必照搬控件，但下面的数据格式、配对规则和交互结果要对齐。

---

## 1. 标签不要写进字幕正文

标签、备注存在独立文件里，不要改 `SubtitleSegment` 的正文，也不要写进 `.srt` / `.vtt`。

这样画面字幕、复制、翻译、生词和笔记仍是原来的台词。标签文件和字幕文件分开拷贝。

---

## 2. 标签文件怎么配对

一个字幕文件对应一个标签文件，只在同一文件夹里按文件名配对。

| 字幕文件 | 标签文件 |
|---|---|
| `lesson_中文.srt` | `lesson_中文.srt.tags.json` |
| `lesson_同步.vtt` | `lesson_同步.vtt.tags.json` |

规则：

- 标签路径 = 字幕所在目录 +「字幕文件名」+ `.tags.json`。扩展名保留，不要只用主文件名。
- 打开字幕时，只找这个同名标签文件。不要按视频名去扫别的目录，也不要套到别的字幕上。
- 标签 JSON 里的 `subtitle_file` 必须等于字幕文件名（含扩展名）。不一致则整份标签作废，不要套用。
- 换设备时，字幕文件和标签文件放在同一文件夹、文件名保持不变，即可自动配对。
- 个别标签对不上新设备上的字幕，是可以接受的。对不上的不要自动安到旁边那句上。

同一部视频可以有多份字幕（例如 `视频名_中文.srt` 和 `视频名_同步.srt`）。每份字幕用自己的标签文件。

## 3. 标签文件格式

UTF-8 JSON，`version` 目前为 `1`。没有标签也没有备注时，删除标签文件，不要留空文件。

```json
{
  "version": 1,
  "subtitle_file": "lesson_中文.srt",
  "entries": [
    {
      "id": "a1b2c3d4e5f6",
      "index": 12,
      "start": 12.5,
      "end": 15.2,
      "text": "打标签时的整句正文",
      "tags": ["重点", "难点"],
      "note": "这里虚拟语气没听清"
    }
  ]
}
```

字段：

| 字段 | 含义 |
|---|---|
| `id` | 这条标签记录的固定编号，12 位十六进制即可。只存在于标签文件，不写进字幕。 |
| `index` | 打标签或上次在本应用内编辑时的字幕序号。 |
| `start` / `end` | 秒，浮点。和字幕时间轴同一套时间。 |
| `text` | 当时的字幕正文快照，用来以后对上是哪一句。 |
| `tags` | 标签名数组。可以多个。 |
| `note` | 备注。可以很长，也可以为空字符串。 |

`tags` 和 `note` 都空时，这条记录不要保存。

## 4. 预设标签、自定义标签、颜色

预设标签，按这个顺序显示：

1. 重点
2. 难点
3. 易错
4. 跟读
5. 已掌握

自定义标签排在预设标签后面。自定义标签最长 48 个字符。名字只在当前这部视频里出现：打标签对话框的候选项，只收集这部视频自己各份字幕标签文件里已经用过的自定义名字。换一个视频文件后，不要带上别的视频里用过的自定义标签。同一部视频的不同字幕之间可以共用这些名字。

一条字幕可以同时有多个标签。

列表左侧色条只取一个颜色，优先级：难点 > 重点 > 易错 > 跟读 > 已掌握 > 其余自定义标签里的第一个。

建议色块（深底浅字，深色背景上能看清）：

| 标签 | 底色 | 字色 |
|---|---|---|
| 重点 | `#6b5420` | `#ffd78a` |
| 难点 | `#6b3030` | `#ffb0a8` |
| 易错 | `#6b4520` | `#ffc48a` |
| 跟读 | `#1e3d55` | `#b9e0ff` |
| 已掌握 | `#1e3d32` | `#9ddeb8` |
| 自定义 | `#3a3a3a` | `#dddddd` |

「已掌握」如果是这条字幕的唯一标签，正文可以变暗。若同时还带别的标签，正文不要变暗。

画面上的字幕不要画出这些标签色块。

---

## 5. 打开字幕时如何把标签挂回去

不要只靠起始时间。按下面顺序，一条标签最多挂到一句字幕，一句字幕最多挂一条标签记录：

1. 起始时间相同（按毫秒比较，允许 1 毫秒误差）并且正文接近，就挂上。正文完全一致算接近；两边去掉空白后至少 8 个字符，并且相似度 ≥ 0.82，也算接近。
2. 时间对不上时，序号还是原来的，并且正文接近，就挂上。
3. 序号也变了，全文里只有一句正文（规范化后）完全相同，就挂上。若有多句相同，只有最近的一句比第二近的一句至少远 1 秒，才挂到最近的那句。
4. 仍然对不上的，放进「未挂上」。保留原来的时间、正文、标签和备注。不要自动安到时间相近的另一句。

在本应用里编辑某一句的起始时间、结束时间或正文时，不要拿旧时间去重新查找。编辑的时候已经知道是哪一行，把该行标签记录里的 `index`、`start`、`end`、`text` 改成新值，标签名和备注不动，然后和字幕一起保存。这样用户在应用里改时间后，标签还在。

如果用户在别的软件里只改了字幕、没改标签文件，才走上面的自动对齐。对不上就进「未挂上」。

---

## 6. 打标签

字幕条目的菜单里提供：

- 标签：打开对话框。
- 清除标签：去掉选中句上的标签记录。

对话框：

- 预设标签用勾选，可多选。
- 可以新增自定义标签，确认后才会写进文件。
- 备注用多行文本，不设最大长度。
- 只选了一条时，打开对话框就带上这条已有的标签和备注，确认后覆盖。
- 多条一起改时，勾选结果会设到每一条上。备注默认不改；用户明确选择「把备注设为上面的内容」后才覆盖各条备注。
- 标签和备注都空了，就删除这条标签记录。

边播边转尚未完成、字幕文件还是临时文件时，不允许打标签，也不允许编辑字幕。

---

## 7. 字幕列表里怎么显示

没有标签、也没有备注的句子，显示和原来一样。

有标签时：

- 普通模式：第一行仍是序号和时间，色块紧跟在时间后面。第二行只放字幕原文。有备注才出现第三行。
- 紧凑模式：不显示序号和时间。色块放在正文前面。
- 条目最左侧加一条约 3 像素的色条，颜色按第 4 节的优先级。
- 备注只用一行。一行显示不下时，截取前面部分，后面用省略号。不要把长备注在列表里全部展开。
- 备注颜色要用亮金色 `#ffd56a`，不要用接近背景的灰色。备注是用户专门写下的内容，必须一眼能看清。已掌握句的正文即使变暗，备注也保持这个亮色。

备注的查看和修改：

- 鼠标停在列表里的备注上，弹出全文。这段全文可以滚动，但鼠标移开后可以关掉。
- 点击这段全文，或点击列表里的那一行备注，打开一个单独窗口。
- 这个窗口在鼠标移开后仍然留着。里面可以改备注，保存后写回标签文件。
- 点备注不要当成点字幕跳转。点正文其它位置仍然跳转播放。

## 8. 筛选和跳转

当前字幕没有任何标签、也没有未挂上记录时，不显示筛选条。

有标签时：

- 预设标签在前，自定义标签在后。每个按钮显示「名字 + 条数」，例如 `重点 4`。
- 有对不上的记录时，再显示 `未挂上 N`。
- 宽度不够时自动换行。自定义标签放不下就换到下一行。一条自定义标签长过整行时，按钮只显示前面一段，并且单独占一行；停在按钮上可以看到全名。
- 「全部」「上一条」「下一条」是一组。这一组在当前行放得下就留在标签后面；放不下就单独占最下面一行。不要和标签挤在同一行里互相挡住。

筛选规则：

- 「全部」显示每一句字幕。
- 可以同时点亮多个标签。列表显示「带有其中任意一个所选标签」的句子，不是必须同时具备全部标签。
- 再点一次已选中的标签，取消它。一个都不选时，回到「全部」。
- 「未挂上」单独看那些没挂上的书签，点击仍按标签里的视频时间播放。它和普通标签筛选互斥。
- 「上一条 / 下一条」在当前筛选结果里的已标记句子之间跳，并开始播放。筛选为「全部」时，在所有打过标签的句子之间跳，不要停在没有标签的句子上。
- 正在播放的句子如果不在筛选结果里，不要把它插回列表。用户点「全部」再看上下文。
- 如果正在按某个标签筛选，用户把标签全部清掉，筛选条会消失。这时必须取消筛选，把每一句字幕重新显示出来。不能留下一个空列表。

未挂上的条目不要插进正常句子中间。右键可以「挂到当前句」或「删除这条标签」。挂到已有标签的句子时，标签名合并，备注只在原句备注为空时采用这条未挂上的备注。

## 9. 同步标签文件

在工具菜单中提供「同步标签文件」。流程：

1. 必须先打开要接收标签的视频。同步目标是这个视频所在的文件夹。
2. 先弹出说明，用户确认后再选文件。说明里要写清：选择一个或多个从其它设备复制来的 `字幕名.扩展名.tags.json`；只有当前视频文件夹里存在同名字幕才会接受；没有标签文件就复制，已有则合并；对不上的条目会留在「未挂上」；不修改字幕正文，也不改用户选中的源文件。
3. 对每个选中的标签文件：
   - 文件名不是「字幕文件名 + `.tags.json`」，跳过。
   - 当前视频文件夹里没有这个字幕文件，跳过。
   - JSON 无效、`subtitle_file` 与文件名不一致、或没有任何有效条目，跳过。
   - 源文件就是目标位置上的那份标签文件，跳过。
   - 目标字幕还没有标签文件：把内容复制到 `文件夹/字幕文件名.tags.json`。
   - 已经有标签文件：合并。同一条记录（先看 `id`，再看时间加接近正文，再看序号加接近正文，再看唯一相同正文）合并标签名，备注不同则追加。对不上的外来条目追加进去。不要删除这边原来的标签。
4. 完成后列出复制了哪些、合并了哪些、跳过了哪些。如果当前正打开的字幕被更新了，刷新列表上的标签。

两边都按这个文件格式读写后，Windows 和安卓可以互相拷贝标签文件再执行同步。

## 10. 画面字幕在沉浸列表下的位置

仅当「显示画面字幕」并且「沉浸列表」同时打开时：

- 水平方向不要在整幅画面宽度里居中。
- 先扣掉沉浸列表所占宽度，在剩下的画面里居中。列表在右侧，字幕就在左侧剩余区域居中；列表在左侧，字幕就在右侧剩余区域居中。
- 字幕条的宽度百分比，也按这块剩余区域计算，避免字幕伸进列表下面。
- 垂直位置不变，仍按用户选择的上、中、下，相对整幅画面高度放置。
- 拖动列表宽度时，字幕的水平位置跟着变。
- 关闭沉浸列表后，恢复为在整幅画面宽度里居中。

桌面版列表宽度算法：按画面宽度的百分比，限制在 18% 到 70%，并且至少 180 像素、至多画面宽度的 70%。安卓若列表宽度不是这个比例，就用实际盖住画面的那一块宽度来扣。

## 11. 打开文件与打开目录

这两项不是标签格式的一部分，但是今天同一批播放器改动。

打开目录：

- 在窗口顶部、当前文件名后面放「打开目录」。
- 还没打开媒体时按钮不可用。
- 点击后打开该媒体文件所在的文件夹，方便查看同目录的字幕、标签和其它文件。安卓可用系统文件管理器打开该目录。

打开文件：

- 原来的「打开媒体」按钮改名为「打开文件」。
- 点击后是菜单，不是直接弹出文件选择框。
- 第一项是「打开媒体」，行为与原来的选择文件相同。
- 下面列出最近使用的 6 个文件，点一下直接打开。
- 若还有更早的记录，再放「更多」。它的子菜单列出第 7 到第 15 个最近文件。
- 最多记住 15 个，新打开的排在最前，重复打开同一文件只保留一条。
- 拖入或用「打开媒体」选中的文件也要记入这个列表。
- 文件已经不存在时，菜单里不要显示。同名文件来自不同文件夹时，菜单文字要带上所在文件夹名，避免分不清。

## 12. 安卓实现时建议保持一致的结果

用户把 `某字幕.srt` 和 `某字幕.srt.tags.json` 从电脑拷到平板的同一目录后：

- 打开该字幕能看到原来的标签和备注。
- 在应用内改过的起始时间，标签仍然挂在那一句上。
- 字幕若在另一台被改过，对得上的挂回去，对不上的进「未挂上」，而不是标错句子。
- 在安卓上新建或修改的标签，用同一 JSON 写回后，桌面版也能读。

## 13. 显示或隐藏字幕列表

有时用户只想把播放器当普通播放器，把字幕列表藏起来。在画面字幕设置里增加开关「显示字幕列表」，和「显示画面字幕」同一级。

- 默认勾选，字幕列表显示。
- 取消勾选后，立刻隐藏字幕列表，画面占满播放区。沉浸列表如果开着，叠在画面上的列表也一起隐藏，画面字幕改回在整幅画面宽度里居中。
- 再次勾选后，列表按原来的位置和沉浸设置恢复。沉浸列表的左/右、透明度和宽度不要因为这次隐藏而丢掉。
- 这个开关不写入配置，也不跟着上一个视频走。每打开一个新的媒体文件，都重新显示字幕列表。
- 正在播放的视频、字幕正文和标签文件都不要因为隐藏列表而被关掉或改写。

## 14. 画面字幕设置的分组和预览

设置分成上下两组，不要把画面字幕和字幕列表的控件混在一起。

- 上面是「字幕列表」：总开关「显示字幕列表」，下面是沉浸列表、列表位置、列表背景透明度、拖动宽度的说明。
- 下面是「画面字幕」：总开关「显示画面字幕」，下面是字体大小、文字颜色、底条透明度、字幕宽度、字幕位置。
- 总开关本身始终可以点。关掉某一组时，这一组里的其余控件留在原地，只变为不可用，不要隐藏或把对话框撑高、缩短。
- 「沉浸列表」关掉时，列表位置、背景透明度和拖动说明仍然显示，只是不可用。只有「显示字幕列表」和「沉浸列表」都打开时，这几项才可改。
- 「显示画面字幕」关掉时，字号、颜色、底条、宽度、位置不可用，但仍然显示。
- 分组标题必须和底色有足够对比，不能用接近底色的浅字。
- 对话框按主窗口居中打开，打开之后位置和大小固定。勾选预览时不要跟着画面区域重排，也不要挪动对话框。
- 对话框背景要半透明（桌面版整窗约 82% 不透明），让被挡住的画面字幕仍能看见调整结果。文字仍要能读清。
- 修改是即时预览。点确认才写入配置。「显示字幕列表」除外，它只对当前视频有效。
- 设置有改动时，用户点窗口关闭而没有点确认，要询问「确认修改」还是「放弃修改」。确认则保存当前预览；放弃则恢复打开对话框前的设置。关掉这个询问本身时，对话框留着，不要当成放弃。没有任何改动时直接关闭。明确点「取消」就是放弃，不必再问一次。

## 15. 批量同步标签

在「同步标签文件」旁边再提供「批量同步标签」。第 9 节仍是针对当前打开的那一个视频；这一节是一次处理很多视频。合并规则与第 9 节相同：没有标签文件就复制，已有则合并，不替换、不删原有标签，不改字幕正文，不改用户选中的源文件。

选择方式：

- 标签来源是多选文件，文件类型为 `*.tags.json`。不要让用户选标签文件夹。选文件夹时用户点进去常常看不到这些文件，会以为选错了。
- 接收端仍选择一个视频文件夹，包含它的子文件夹。
- 选完后记住这两项。下次再打开时，填回上次仍存在的标签文件和视频文件夹；再点选择时，也从上次的位置打开。已经不存在的路径不要再填。桌面版记在程序配置里，字段是 `batch_tag_sync_files` 和 `batch_tag_sync_video_dir`。安卓记在自己的偏好里即可，不必共用这个 JSON。

匹配：

- 从标签文件名得到字幕名。`lesson_中文.srt.tags.json` 对应字幕 `lesson_中文.srt`。
- 在视频文件夹及子文件夹里找视频。字幕主文件名与视频主文件名相同，或是「视频主文件名_」开头（例如 `视频名_中文.srt` 对应 `视频名.mp4`），算同名。
- 视频旁边必须已经有这份同名字幕，才列入结果。没有字幕就无法写入标签，不要列出来。
- 标签文件无效、内部 `subtitle_file` 与文件名不一致、或源文件就是目标位置上的那份标签文件，都跳过。
- 同一个标签可以对应不同子文件夹里的多部同名视频，每一对占一行。

结果列表：

- 列：复选框、视频文件名、文件路径、标签文件名、是否已有标签。
- 复选框默认不选。提供全选、全不选、反选。只有勾中的行才会同步。
